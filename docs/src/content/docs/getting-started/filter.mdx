---
title: Filters and Route Security
---

Diesel makes it easy to manage both public and protected routes using the `filter` middleware from `diesel-core/filter`. With `filter()`, you can define specific routes as publicly accessible while enforcing authentication or custom middleware for protected routes. This approach enables fine-grained control over route security, ensuring sensitive resources are well-guarded.

### How to Use `filter()`

`filter()` is a regular middleware — register it with `app.use()` like any other. Pass `publicRoutes` to mark specific routes as public, and `authenticate` with one or more middleware functions to guard everything else. This flexibility helps keep user information secure while providing accessible, unauthenticated routes as needed.

### Example Usage
Using `filter()` with JWT Authentication and Middleware

```typescript
import { Diesel } from "diesel-core";
import { filter } from "diesel-core/filter";
import authJwt from "./middleware/authJwt";
import rateLimiter from "./middleware/rateLimiter";

const app = new Diesel();

// Define routes and apply the filter
app.use(filter({
  publicRoutes: ["/api/user/register", "/api/user/login", "/cookie"], // Public routes
  authenticate: [authJwt, rateLimiter], // Apply multiple middleware to protected routes
}));

// Public route example (no authentication needed)
app.get("/api/user/register", async (ctx: ContextType) => {
  return ctx.json({ msg: "This is a public route. No authentication needed." });
});

// Protected route example (requires authentication and rate limiting)
app.get("/api/user/profile", async (ctx: ContextType) => {
  const user = ctx.get("user");
  return ctx.json({
    msg: "You are authenticated!",
    user,
  });
});
```

### Built-in JWT Authentication Filters
**`authenticateJwt()`** from `diesel-core/jwt`
`authenticateJwt({ app, jwt, jwtSecret })` provides an inbuilt JWT authentication middleware you can drop straight into `filter()`'s `authenticate` array. Once applied, you can access the user context via `ctx.get("user")`.


Example Usage:
```ts
import { Diesel } from "diesel-core";
import { filter } from "diesel-core/filter";
import { authenticateJwt } from "diesel-core/jwt";
import jwt from 'jsonwebtoken'

const app = new Diesel();

// Define routes and apply the filter
app.use(filter({
  publicRoutes: ["/api/user/register", "/api/user/login", "/cookie"], // Public routes
  authenticate: [authenticateJwt({ app, jwt, jwtSecret: "your-secret" })], // Inbuilt jwt middleware
}));

  // and you will get `user` Context in ctx.get('user')
  app.get("/profile", async(ctx) => {
    const userDetails = ctx.get("user")
    return ctx.json({ user: userDetails });
  })

```
**`authenticateJwtDB()`** from `diesel-core/jwt`
`authenticateJwtDB({ app, userModel, jwt, jwtSecret })` integrates JWT authentication with a database model for user validation.

Example:

```ts
import { Diesel } from "diesel-core";
import { filter } from "diesel-core/filter";
import { authenticateJwtDB } from "diesel-core/jwt";
import jwt from 'jsonwebtoken'
import UserModel from "./schema/userModel"

const app = new Diesel();

// Define routes and apply the filter
app.use(filter({
  publicRoutes: ["/api/user/register", "/api/user/login", "/cookie"], // Public routes
  authenticate: [authenticateJwtDB({ app, userModel: UserModel, jwt, jwtSecret: "your-secret" })], // Inbuilt jwt + DB middleware
}));

  // and you will get `user` Context in ctx.get('user')
  app.get("/profile", async(ctx) => {
    const userDetails = ctx.get("user")
    return ctx.json({ user: userDetails });
  })

```

### Breakdown of `filter()` Options

* `publicRoutes: string[]`: Specifies which routes should be public (unauthenticated). Matched by path prefix.

```typescript
filter({ publicRoutes: ["/api/user/register", "/api/user/login"] })
```

* `authenticate: middlewareFunc[]`: Defines one or more middleware functions, run in order, for routes not included in `publicRoutes`. If the array is empty, Diesel defaults to an "Unauthorized" response for any non-public route.

```typescript
filter({ authenticate: [authJwt, rateLimiter] })
```

* Combine with `authenticateJwt({ app, jwt, jwtSecret })` or `authenticateJwtDB({ app, userModel, jwt, jwtSecret })` from `diesel-core/jwt` inside `authenticate` for built-in JWT support instead of writing your own.

### Use Cases

#### **Public Routes**
Routes like `/api/user/register` and `/api/user/login` are often public to allow user registration and login without prior authentication. List them in `publicRoutes` to skip authentication for them.

#### **Protected Routes**
For routes handling sensitive information (e.g., `/api/user/profile`), apply `authenticate: [authJwt, rateLimiter]` to enforce authentication and other security layers. Only users with valid JWTs and within rate limits will be able to access these routes.

### Benefits of Using `filter()` in Diesel

✅ **Just a Middleware** – `filter()` is a regular `app.use()` middleware, so it composes naturally with the rest of your middleware stack.

✅ **Flexible Security** – Easily toggle between public and protected routes.

✅ **Centralized Authentication** – Manage route security in one place for cleaner, more maintainable code.

✅ **Scalable Middleware** – Supports multiple middleware functions per route for enhanced security and functionality.

With Diesel's `filter()`, securing routes becomes efficient, clear, and adaptable, allowing you to manage public and private endpoints seamlessly.
